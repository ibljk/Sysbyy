> 最后更新：2026-09-07 22:59 · 演示环境三端在线（MySQL 3317 / 后端 8080 / 前端 5173）

## 一、项目概况

高校实验室设备预约管理 Web 应用，前后端分离、开箱即用。用户端浏览带图设备并发起预约、本人拍照归还；管理端维护设备与图片、审批核验、统计看板。前端依赖全部内置 `frontend/lib/`，**离线可演示**。

| 项 | 内容 |
|----|------|
| 技术栈 | Spring Boot 2.7.18 + MyBatis-Plus 3.5.3 + MySQL 8.0 + JWT；Vue 3 + Element Plus + ECharts |
| 演示库 | `lab_equipment`（MySQL 8，端口 **3317**，root 空密码），**11 张表**：12 台设备（40 台总库存）+ 15 条预约 + 4 条公告 + 3 条维护窗口 + 4 条资质 + 3 条报修工单 |
| 演示账号 | `admin` / `student1` / `teacher1`（密码均 `123456`），另有 `teacher2` / `student2` |
| 资质演示 | student1 持 EQ-0009 激光切割机 / EQ-0011 离心机资质；teacher1、student2 无该资质（可演示准入拦截） |
| 服务地址 | 后端 http://localhost:8080（demo profile）· 前端 http://127.0.0.1:5173 · MySQL 127.0.0.1:3317 |

## 四、关键业务规则（最新口径）

- **预约校验链（8 步）**：① 参数合法性（含最多提前 30 天）→ ② 设备加锁 + `REPAIR` 拦截 → ③ **仪器级规则** → ④ **维护窗口** → ⑤ **资质准入** → ⑥ 实验室开放时间 → ⑦ 台数冲突 → ⑧ 创建。
- **规则优先级**：`equipment.min_minutes / max_days / allow_cross_day` 优先，为空回退 `sys_config` 全局值（默认最短 30 分钟、最长跨度 30 天含首尾）；`allow_cross_day=0` 时该设备仅可约同一天内的时段。
- **设备库存**：每单占用 1 台；同设备同段重叠占用数 `< stock` 才允许新单；`REPAIR` 设备禁止预约。
- **同段多台**：同一用户可同时预约多台**不同设备**（仅受各设备自身库存上限约束）——2026-09-07 应需求放开。
- **占用统计**：`occupiedNow` 实时计算（`status='APPROVED'` 且时段覆盖当前时刻），不做状态持久化；设备状态仅维护 `IDLE` / `REPAIR`。
- **并发安全**：发起/审批均对设备行 `SELECT ... FOR UPDATE` 悲观锁，校验与写入同事务。
- **归还核验**：仅预约本人或管理员可归还；仅 APPROVED 可归还；必须上传归还照片。
- **维护窗口**：窗口内设备不可预约；创建时与已有预约（待审批/已通过）时段重叠则**拒绝创建**；状态按时间惰性流转（计划 → 执行中 → 已完成），仅「计划」可删除。
- **资质准入**：`need_qualification=1` 的设备，仅持 `VALID` 且未过期资质（`valid_until IS NULL` 或 ≥ 今天）的用户可预约；同一设备+用户唯一，重复授予刷新有效期。
- **报修工单**：`待处理 → 处理中 → 已完成`，完成写处理人与处理时间，已完成不可重复处理。
- **公告可见性**：仅 `PUBLISHED` 对用户端可见，关闭后立即消失；横幅取最新 3 条，用户关闭仅本地记忆。

## 六、演示步骤（30 秒上手）

1. 三端启动（见下节）后浏览器打开 http://127.0.0.1:5173
2. 用 `student1` 登录 → 设备预约：选有库存的设备（如 EQ-0001 数字示波器 ×5）→ 立即预约 → 日期区间 + 时段 + 用途 → 提交
3. 用 `admin` 登录 → 预约管理：通过该单 → 统计看板观察台数变化
4. 回到 `student1` → 我的预约：对已通过单拍照上传归还 → admin 预约管理核验照片
5. 说明库存：admin 设备管理把某设备设为"维修"→ 学生端该卡立即显示维修中且按钮禁用
6. **公告**：admin 「公告管理」发布一条紧急公告 → 学生端设备预约页顶部立即出现横幅，点"全部公告"进列表
7. **仪器级规则**：admin 设备管理编辑 EQ-0001 → 最短时长设 1 小时且关闭跨天 → 学生预约 30 分钟或跨天被拒并给出对应提示
8. **维护窗口**：admin 「维护报修」为某设备创建维护时段（该段无预约）→ 学生预约该时段被拒 → 管理员"结束维护"后恢复可约；若选已有预约的时段，创建会被直接拒绝
9. **资质准入**：admin 「资质认证」撤销 student1 对 EQ-0009 激光切割机的资质 → 学生预约该设备被拒（提示需持证）；重新授予后可约
10. **报修**：student1 「设备报修」提交故障 → admin 「维护报修 → 报修工单」受理并完成 → 学生端看到处理说明
11. **操作日志**：admin 「操作日志」可看到上述所有动作留痕（按类型筛选如"发布公告""创建维护窗口"）
