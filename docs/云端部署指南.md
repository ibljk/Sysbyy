# 云端部署与在线访问指南

> 目的：让**小组成员在线打开链接就能使用系统**（无需安装 JDK / MySQL / Maven）
>
> 项目为此专门提供了 `cloud` 运行模式：**内置嵌入式数据库（H2）+ 前端由后端一并托管**，
> 因此整个系统只占用**一个 HTTP 端口**，无需额外部署数据库。

---

## 一、先理解两种运行模式

| | **default（本地开发）** | **cloud（单端口部署）** |
|---|---|---|
| 数据库 | MySQL 8（需自行安装并初始化 `db/init.sql`） | **H2 内存库**（启动时自动建表灌数据） |
| 前端 | 单独启动静态服务（5173 端口） | **由后端托管**，与接口同源（8080） |
| 端口 | 8080 + 5173 两个 | **仅 8080 一个** |
| 适用场景 | 本地开发调试 | 云端部署 / 演示 / 分享给他人 |

`cloud` 模式的数据库是**内存库**：进程重启即恢复为干净的演示数据（12 台设备、15 条预约、4 条公告……），
这对答辩演示反而是优点——不用手动清库。

---

## 二、方式一：本地一键运行（最简单，验证用）

适合自己先跑通、或让队友在自己电脑上体验。

```bash
# 1. 打包（首次会下载依赖，约 2-5 分钟；之后几秒）
cd backend
mvn clean package -DskipTests

# 2. 启动（单端口，前端 + 接口都在 8080）
java -jar target/lab-equipment-reservation-1.0.0.jar --spring.profiles.active=cloud
```

浏览器打开 **http://localhost:8080** 即可，默认账号 `admin / 123456`。

> 前置条件只有 **JDK 8+** 与 **Maven**。不需要 MySQL。
> 若本机环境变量里存在 `SERVER_PORT` 之类的配置覆盖了端口，用 `--server.port=8080` 显式指定。
>
> **Linux / macOS / 云服务器**可直接运行项目根目录的一键脚本，它会自动检测并安装依赖后启动：
> ```bash
> bash start-cloudstudio.sh
> ```

## 三、方式二：Cloud Studio 云端部署（队友在线访问）

[Cloud Studio](https://cloudstudio.net/) 是腾讯云的云端 IDE，支持从 GitHub 导入仓库、在线运行，并可为端口生成**公开访问链接**。

### 步骤 1 · 登录并创建空间

1. 打开 https://cloudstudio.net/ ，用**微信 / GitHub** 登录（无腾讯云账号需先注册并实名）
2. 进入工作台，点击 **新建工作空间**
3. 代码来源选择 **导入仓库**：首次使用需先绑定 GitHub 账号，然后选择本仓库与分支 `main`
4. 环境模板选择 **Java**（Spring Boot 模板，自带 JDK 与 Maven）
5. 点击创建，等待 1-2 分钟环境就绪

### 步骤 2 · 打开空间后自动启动（无需敲命令）

本仓库已内置 Cloud Studio 自动运行配置 **`.vscode/preview.yml`**，工作空间打开后会**自动执行启动脚本**
`start-cloudstudio.sh`：依次检测/安装 JDK 与 Maven → 编译 → 以单端口模式启动，并自动打开预览窗口。

- **首次启动**：需要编译并下载 Maven 依赖，约 **2-5 分钟**（看底部终端进度即可）
- **之后启动**：检测到已编译的 jar 会跳过编译，约 **10 秒**

启动成功的标志（终端出现）：

```
[4/4] 启动服务，端口 8080 ...
Started LabEquipmentApplication in 7.2 seconds
```

> **如果自动启动没触发**（例如平台未识别配置），手动执行一次即可：
> ```bash
> cd lab-equipment-reservation        # 目录名以导入后的实际路径为准
> bash start-cloudstudio.sh
> ```

### 步骤 3 · 把端口设为公开访问

1. 找到 IDE 底部的 **「端口」面板**（Ports）
2. 找到 **8080** 端口，点击右侧的 **「公开」/「预览」** 按钮
3. 复制生成的访问链接，形如：
   ```
   https://<你的空间标识>-8080.<域名>
   ```

### 步骤 4 · 分享给组员

有两种方式，任选其一：

- **直接发端口链接**：把步骤 3 复制的链接发给组员，浏览器打开即可使用（选择「所有人可访问」时无需登录）
- **走应用分享入口**：个人中心 → 应用管理 → 应用卡片「…」→「分享」→ 访问范围选 **所有人可访问** → 复制链接

组员打开链接后，用 `admin / 123456` 或 `student1 / 123456` 登录即可。

### 注意事项

- **休眠**：Cloud Studio 免费版在空闲一段时间后会自动休眠，组员访问前需要在工作台点击唤醒（约 1 分钟）。答辩前建议提前唤醒一次。
- **额度**：免费版每月有在线时长额度，用完需等次月或升级，日常演示足够。
- **数据**：内存库，重启即回到初始演示数据，不会累积脏数据。

## 四、方式三（备选）：GitHub Codespaces

若已有 GitHub 账号，也可以直接用 Codespaces（GitHub 自带云端开发环境）：

1. 打开仓库页面 → **Code** → **Codespaces** → **Create codespace on main**
2. 在终端执行第三节「步骤 2」的同样两条命令
3. 在 **PORTS** 面板把 8080 的可见性改为 **Public**，复制转发地址分享

> 注意：`*.app.github.dev` 域名在部分网络环境下访问可能不稳定，国内演示优先选 Cloud Studio。

## 五、常见问题

**Q：为什么不能直接用 MySQL 部署到云上？**
A：多数免费云开发环境只提供**单个 HTTP 端口**，不会附带可长期运行的 MySQL 服务。`cloud` 模式用嵌入式 H2 替代，效果与 MySQL 版本一致（表结构、接口、界面完全相同）。

**Q：cloud 模式的数据会不会和 MySQL 版不一致？**
A：不会。`backend/src/main/resources/db/h2/` 下的 `schema.sql` 与 `data.sql` 由 `db/init.sql` 与 `db/seed-equipment-photos.sql` **自动转换生成**，表结构、种子数据、设备配图与 MySQL 版一一对应。

**Q：改了 `db/init.sql` 后，H2 脚本怎么同步？**
A：重新生成即可，转换脚本会处理 MySQL→H2 的语法差异（索引与约束命名、日期函数、自增序列等）。

**Q：端口链接打不开？**
A：依次检查——① 服务是否在运行（终端有没有 `Started LabEquipmentApplication`）；② 端口面板里 8080 是否已设为公开；③ 工作空间是否已休眠需要唤醒；④ 稍等几秒等反向代理生效后刷新。

**Q：能改成账号不登录也能浏览吗？**
A：系统接口需要 JWT 鉴权，必须登录。可以直接用内置演示账号，无需注册。
